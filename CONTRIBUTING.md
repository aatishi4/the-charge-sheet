# Contributing

Thanks for helping make this better. The most useful contributions, in order:

## 1. Corrections

Found a wrong number, an outdated rule or a broken tool? Open an issue with:

- the page or tool,
- what it says,
- what it should say, and a source if you have one.

Incentives, loan rules and tariffs change often. Dated corrections are very welcome.

## 2. Site data

The benchmarks get better with every real site. If you operate chargers and can share session exports,
open an issue or use the contact form on the site. Useful fields:

- start and end time for each session, and energy delivered,
- charger and connector identifiers (any internal ID is fine),
- session status (finished or failed),
- site type, rough region, charger power and price per kWh.

Everything is anonymized before publication: no names, addresses, hosts, operators or drivers,
and locations generalized to a region. Please only share data you have the right to share.

## 3. Code

The site is deliberately one HTML file with no build step, so anyone can open it and read it.

- Keep it dependency-free and working when opened directly or served from any static host.
- Test on a phone, in dark mode, and with reduced motion turned on.
- Keep the writing plain and direct, with numbers people can check.

Open a pull request with a short description of what changed and why.
